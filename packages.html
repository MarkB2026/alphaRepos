Packages help you discover related applications. An application appearing in more than one package is the same download and version, not a different edition. Individual downloads remain available.

Release status guide

PRE-BETA Core connect–trade–disconnect workflow demonstrated for trading bots; other advertised features may still be incomplete or unverified. For non-trading tools, core functionality is still under early testing.

BETA Advertised features have been wired and functionally tested; broader testing continues.

Production is reserved for stable, validated releases, with additional live-market testing requirements for trading bots.

GOOD TO KNOW

FREQUENTLY ASKED QUESTIONS.

Do I need to install broker or Python libraries?

No. Everything you need is included in the installation package. You will still need your broker’s supported trading platform or connection configured to place trades.

Can I use these bots on my phone?

No. These bots are built for Windows trading workstations, not phones. Gamers build gaming rigs. Serious traders build trading rigs.

Can I buy individual applications?

Yes. Every listed application can be selected individually; packages are simply a convenient way to browse related tools.

Do I need a cloud subscription?

No. Everything runs locally on your computer and connects to your broker automatically when you are logged in.

Do the tools automatically share strategies?

Only supported integrations do. Some research exports require review, import and explicit confirmation; other integrations are still being developed.

Are package prices available?

Packages are curated discovery groups, not separate editions. Check the individual software catalog for available downloads and pricing.
