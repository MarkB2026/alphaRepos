TraderRepos product gallery setup

Upload the pages/ folder and coming-soon.html to your site root.
Keep your existing index.html, checkout and product-theme.css unchanged.

To add screenshots to a product, create assets/product-images/PRODUCT-SLUG/ and upload files named 1.png, 2.png, 3.png, up to 6.png.
Example: assets/product-images/mini-scalper/1.png
The gallery automatically detects available numbered PNGs, displays uniform thumbnails and opens the originals in a full-size lightbox. If none are present it displays a Coming Soon link.

The existing Option Price Plotter page retains its six original screenshot references and demo video.

This ZIP includes product HTML pages only and a Coming Soon page; existing images, videos and CSS must remain on your server.

NOTE: This does not rewrite the homepage product-card links, which continue pointing to product pages. Missing screenshots show Coming Soon within the product pages.
