PRODUCT DETAILS

HAL Think Box

Go beyond preset strategies. Build precise pattern-entry rules in the Custom Pattern Rule editor, or try describing an idea in everyday language using the new Plain English (Beta) tab.

EARLY BETA — Plain English currently uses a limited phrase interpreter, not an AI language model. Its JSON output is an editable preview only: it is not saved, validated as a live rule or sent to the trading engine. More language understanding, patterns and rule options are planned. Availability depends on bot and edition.

Features and capabilities

  • Pattern Library: explore supported triangles, double tops and bottoms, engulfing candles, hammers and shooting stars.
  • Custom Pattern Rule: configure touches, breakout confirmation, RVOL, time windows and other pattern-specific conditions. Supported saved rules can filter new entries.
  • Plain English (Beta): type a trading instruction, click Preview JSON , then edit the generated JSON draft directly.
  • See your logic: inspect rule settings and, for supported saved pattern rules, review entry-blocking decisions.

How it works

User-defined rules; execution depends on the connected bot

Features

  • Define entry rules with supported pattern, volume, time and confirmation conditions.
  • Early beta: available controls vary by connected bot.

Compatibility & installation

  • Windows desktop application (not designed for phones).
  • 32-bit / 64-bit Windows: compatibility is build-dependent and must be verified before release.
  • IBKR integration on supported trading-bot builds; not every research tool requires a broker connection.
  • MetaTrader 5 (MT5): beta testing / planned integration; not generally released for live execution.
  • Packaged installers are intended to include required Python and broker libraries; verify each release package.
  • A supported broker platform/account and market-data permissions may still be required for trading.

Availability, execution modes and integrations depend on the specific tested build. Paper-test order execution before live trading.
